# メモ常駐アプリ UI/状態仕様（v0.1）

更新日: 2026-02-14  
対象: Windows 10/11, macOS（共通UI + OS別実装）

## 0. 前提
- 本仕様は「ホットキーで呼び出す常駐メモアプリ」のMVP仕様である。
- 技術スタックは `.NET 8 + Avalonia` を前提にする。
- 用語:
  - 「メモ一覧領域」の正式名を `メモリストペイン` とする。
  - 「メモ内容領域」の正式名を `メモ詳細ペイン` とする。

## 1. UIコンポーネント一覧
| ID | コンポーネント名 | 役割 | 主な操作 |
|---|---|---|---|
| UI-01 | ルートポップアップウィンドウ | ホットキーで表示/非表示される本体 | 外側クリックで閉じる |
| UI-02 | メモリストペイン | ChatGPTのスレッド一覧のようにメモを縦並び表示 | クリックで選択、ホイールでスクロール、上下キーで選択移動 |
| UI-03 | メモ行アイテム | 1件分のメモ（タイトル、更新日時） | クリックで選択 |
| UI-04 | アーカイブボタン | 対象メモを一覧から非表示にする | クリックでアーカイブ |
| UI-05 | メモ詳細ペイン | 選択中メモの内容を表示/編集 | タイトル編集、本文編集 |
| UI-06 | タイトル入力欄 | メモ詳細ペイン最上部 | テキスト入力 |
| UI-07 | コンテント入力欄 | タイトル直下 | テキスト入力 |
| UI-08 | 設定画面 | ホットキー等の変更 | ホットキー変更、起動時常駐ON/OFF |
| UI-09 | トレイメニュー | 常駐中の操作導線 | 開く、設定、終了 |

### 1.1 固定ルール
- ルートポップアップは Clibor 風の表示を目標とし、タイトルバー/閉じるボタンは表示しない（枠のみ）。
- アプリ表示時、`メモ詳細ペイン` は必ず表示される。
- 初回表示時の選択メモは「先頭メモ（並び順1件目）」とする。
- 保存対象は複数メモ。表示は常に1件（1枚）。

## 2. 状態一覧
| 状態ID | 状態名 | 説明 |
|---|---|---|
| ST-01 | ResidentHidden | 常駐中・ポップアップ非表示 |
| ST-02 | PopupVisible | ポップアップ表示中（編集可能） |
| ST-03 | SettingsVisible | 設定画面表示中 |
| ST-04 | Saving | 保存処理中（バックグラウンド） |
| ST-05 | Locked | 復号鍵が破棄され再認証待ち |

| メモ状態ID | 状態名 | 説明 |
|---|---|---|
| MS-01 | Active | 通常表示対象 |
| MS-02 | Archived | 一覧非表示（アーカイブ済み） |

## 3. 状態遷移表
| 現在状態 | イベント | 次状態 | 動作 |
|---|---|---|---|
| ResidentHidden | ホットキー押下 | PopupVisible | マウスカーソル右下に表示し、先頭メモを表示 |
| PopupVisible | ホットキー押下 | ResidentHidden | ポップアップを非表示 |
| PopupVisible | 外側クリック | ResidentHidden | 非表示して常駐へ戻る |
| PopupVisible | メモ行クリック | PopupVisible | 選択メモを切り替え、詳細ペイン更新 |
| PopupVisible | `↑/↓` キー | PopupVisible | 前後メモへ選択移動、詳細ペイン更新 |
| PopupVisible | アーカイブ押下 | PopupVisible | 該当メモをArchivedに変更し一覧から除外 |
| 任意 | 保存トリガー | Saving | 暗号化保存（成功後は元状態へ戻る） |
| PopupVisible | 一定時間操作なし | Locked | 復号鍵をメモリ破棄しロック |
| Locked | 認証成功 | PopupVisible | 復号して編集再開 |

## 4. 入力イベント一覧
| イベントID | 入力 | 既定値 | 備考 |
|---|---|---|---|
| EV-01 | グローバルホットキー | macOS=`Shift` 2回連打 / Windows=`Ctrl` 2回連打 | 判定窓は既定300ms、設定で変更可 |
| EV-02 | メモ選択 | 左クリック | クリックしたメモを選択 |
| EV-03 | メモ切替 | `↑/↓` | リスト選択を上下移動 |
| EV-04 | リスト移動 | マウスホイール | リストをスクロール |
| EV-05 | 非表示 | ウィンドウ外クリック | ポップアップを閉じる |
| EV-06 | 設定呼出 | トレイメニュー | 設定画面を表示 |

### 4.1 対応ホットキー種別
- `Shift`
- `Control`
- `Alt`（macOSでは Option）
- `Command`（Meta）

## 5. 表示ルール
- ホットキー検知後に即座にポップアップ表示する（通常ウィンドウの開閉体験にはしない）。
- 表示位置は「マウスカーソルの右下」を基準にする。
- 画面端ではみ出す場合は、画面内に収まるよう自動補正する。
- 最小表示保証:
  - `メモ詳細ペイン` は常時表示。
  - タイトル欄 + 本文欄が欠けない最小サイズを維持する。
- 表示中に他アプリ側をクリックした場合は非表示に遷移する。

## 6. エラー時挙動
| ケース | ユーザー表示 | システム動作 |
|---|---|---|
| 保存失敗（I/O） | 「保存に失敗しました」通知 | リトライ導線を表示、ログ記録 |
| 復号失敗（パスワード不一致/破損） | 「復号できません」通知 | 読み取り専用で退避、復旧手順を案内 |
| ホットキー競合 | 「ホットキーを登録できません」通知 | 設定画面へ誘導 |
| データ破損検知 | 「データ修復が必要です」通知 | バックアップから復元提案 |

## 7. OS差分（Mac開発 + Win利用）
| 領域 | 共通化方針 | Windows 10/11 | macOS |
|---|---|---|---|
| UI/画面 | Avaloniaで共通化 | 共通 | 共通 |
| メモ保存/暗号化 | 共通ライブラリ化 | 共通 | 共通 |
| グローバルホットキー | OS別サービスで実装 | Win32 API | Cocoa/Carbon相当API |
| 常駐アイコン | OS別サービスで実装 | 通知領域（トレイ） | メニューバー |
| 自動起動 | OS別サービスで実装 | スタートアップ登録 | Login Items |

### 7.1 開発運用
- 日常開発と一次確認は macOS で実施する。
- Windows固有挙動（ホットキー競合、トレイ、IME）はWindows実機で都度確認する。

## 8. 受け入れ条件（チェックリスト）
- [ ] アプリ起動後、常駐してトレイ/メニューバーにアイコンが出る。
- [ ] macOSでは既定の `Shift` 2回連打、Windowsでは既定の `Ctrl` 2回連打でポップアップが表示される。
- [ ] ポップアップ表示位置がマウスカーソル右下になる。
- [ ] メモ一覧（スレッド風）をクリックすると本文が切り替わる。
- [ ] 初回表示時に先頭メモが自動表示される。
- [ ] 一覧はホイールでスクロールできる。
- [ ] `↑/↓` でメモ選択が切り替わり、本文が即時更新される。
- [ ] アーカイブ操作したメモが一覧から非表示になる。
- [ ] 外側クリックでポップアップが非表示になる。
- [ ] 設定画面でホットキー変更ができ、再起動後も保持される。
- [ ] メモ本文は暗号化されて保存され、平文ファイルが残らない。
- [ ] Windows 10/11 と macOS の両方で同等の基本操作ができる。
