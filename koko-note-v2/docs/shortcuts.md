# Windows／macOS 共通操作仕様

左下の案内表示とノート操作は両OSで揃え、通常の編集操作はWindowsのCtrl、Macの⌘を主修飾キーにします。OS固有の既存操作は互換用に残します。

| 操作 | Windows | macOS |
|---|---|---|
| ショートカット案内 | Ctrlを押している間 | ⌘を押している間 |
| 新規ノート | Ctrl+N | ⌘N |
| 即時保存・再試行 | Ctrl+S | ⌘S |
| ノート一覧・本文／タイトル検索 | Ctrl+L | ⌘L |
| タブを閉じる（削除しない） | Ctrl+W | ⌘W |
| 名前変更 | Ctrl+R、従来のF2も有効 | ⌘R |
| 元に戻す | Ctrl+Z | ⌘Z |
| やり直す | Ctrl+Shift+Z、従来のCtrl+Yも有効 | ⌘Shift+Z |
| コピー・切り取り・貼り付け・全選択 | Ctrl+C / X / V / A | ⌘C / X / V / A |
| 次／前のタブ | Ctrl+Tab / Ctrl+Shift+Tab | Control+Tab / Control+Shift+Tab |
| 表示／前面復帰／非表示 | Ctrl+Shift+Space | Control+Shift+Space |
| 完全削除 | 「ノート」→「ノートを削除…」→確認 | 「ノート」→「ノートを削除…」→確認 |
| アプリ終了 | トレイ→「終了」 | メニューバー→「終了」、または⌘Q |

案内はキー押下で開き、キー解放・フォーカス離脱・非表示で閉じます。キーを押したまま画面へ戻った場合も、現在の修飾キー状態に合わせます。案内は複数行で折り返し、保存状態の上に表示します。保存済み・未保存・保存中・保存失敗は案内と別の表示として維持し、失敗の赤色表示も上書きしません。表示・解除で本文・選択範囲やUndo履歴を変更せず、フォーカスを奪いません。

自アプリのイベントだけを使い、タイマーでキー状態をポーリングしません。Windowsのメッセージフィルターはfalse、Macのローカルモニターは受け取ったイベントを返して入力を通します。グローバルキーボード監視や他プロセスへのキー注入は使いません。

IME変換中は未確定文字を保存対象へ反映しません。ノートの新規・保存・閉じる・検索・名前変更と、追加したWindowsのCtrl+Shift+Zは変換を中断しないよう抑制します。タブ切り替え・非表示・終了の保留規則は各OSの実装に従い、未確定本文を保持します。案内の表示だけではIMEへ確定・取消を要求しません。

削除用ショートカットは設けません。Ctrl/⌘+Wは閉じるだけで、削除は明示的なメニューと確認を必須にします。

Macはこの端末のAppKit統合テストを実行しています。WindowsはクロスビルドとWindows用テストのコンパイルまでで、物理キー・実IME・画面表示の実機検証は未実施です。暗号化や保存先はOS固有の構成を維持します。
